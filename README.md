# AI Data Analyst Assistant

An AI-powered data analytics application built using Python, Streamlit, Pandas, Plotly and Groq.

## Features

- CSV, Excel and JSON data import
- Interactive data exploration
- Data profiling and quality analysis
- Missing-value handling and duplicate removal
- Exploratory Data Analysis dashboard
- Groq-powered AI Assistant for dataset questions
- CSV, Excel, PDF and HTML report exports
- Light and Dark interface themes

## Tech Stack

- Python
- Streamlit
- Pandas and NumPy
- Plotly
- Groq API
- ReportLab
- Matplotlib

## Installation

1. Clone the repository:

   `git clone https://github.com/pratikinkar/AI-Data-Analyst-Assistant.git`

2. Open the project directory.

3. Create a virtual environment:

   `python -m venv .venv`

4. Install dependencies:

   `pip install -r requirements.txt`

5. Create a `.env` file and configure your Groq API key:

   `GROQ_API_KEY=your_api_key`

6. Run the application:

   `streamlit run app.py`

## Project Status

This project is a working prototype. Some analytics and visualizations may depend on the dataset structure. Testing and improvements for broader dataset compatibility are ongoing.
